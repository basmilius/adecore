# Chat reference

Subpaths below are relative to `@adecore/agents-react/`. Each source link provides the exact public signature. The [composer](./composer), [attachments](./attachments), [timeline](./timeline), and [approvals/tasks](./approvals-tasks) guides show how these modules work together.

Use the complete `Timeline`/`Composer` composition unless the host intends to own grouping, prompts, keyboard handling, and scroll registration. Lower-level exported helpers are available for those custom compositions. State belongs to the scope where specified; draft/timeline helpers that take raw chat IDs require those IDs to be unique in the renderer.

## Thread and composer components

`Timeline` takes a chat ID and optional composer/overlay React nodes. `Composer` needs live info, connection/focus flags, and host send/retarget callbacks. `ComposerInput` exposes an imperative handle. `PromptComposer` combines backend and host subjects. Pickers and run settings reuse the backend model descriptors. See the guides for defaults and keyboard behavior.

Limit controls offer host-authorized continuation rather than changing providers silently.
