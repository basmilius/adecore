# Settings reference

Subpaths are relative to `@adecore/agents-react/`. Links open exact source types. These views read the active scope and shared host hooks; they do not detect CLIs, launch login commands, read credentials, or scan transcripts in the renderer.

See [accounts and models](./accounts-models) for settings composition, [usage](./usage) for scanning/subscription lifetime, and [styling](./styling) for theme and locale setup.

## Provider and model display

`AgentIcon` uses the agent kind, while `ProviderLogo` uses the usage-provider kind. Account helpers choose labels/status/colors from the backend account map. Model option helpers retain only accepted descriptor values. Limit continuation helpers require enabled, signed-in accounts with known room and only offer a choice.

## Account forms and settings sections

`ProvidersPane` accepts an optional search target, custom detail, and `defaults` toggle. Other panes take the backend provider/account data documented by their types. Account actions route through the scope transport, update the shared store, and preserve refusals. `variables` validates duplicate/invalid names before producing `ProviderAccountVariable[]`; the backend still enforces its own environment policy. `settingsSection` reads current translated labels when building an entry.

## Usage views and formatters

`UsageDialog` is the controlled frame; `UsagePage` is the scoped body with optional header pickers and a stale-data notice. `UsagePane` needs a host navigation callback. Summary/breakdown/chart/tiles components take derived data and do not start their own scans. The page owns scan subscriptions; limits hooks share a read per scope. Money formatting uses USD source amounts and the chosen display currency/rate.

## Assets

| Entrypoint       | Contents                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| `theme.css`      | Chat/provider/usage tokens and rules; import after the UI theme                                    |
| `locales/*.json` | English/Dutch JSON, such as `locales/en/agent-chat.json`; preserved at matching `src`/`dist` paths |

The runtime `locales` module exports the namespace list and language loaders. The `theme.css` export selects source CSS with the `source` condition and copied CSS under default resolution. Tailwind must also scan component code. Locale JSON files are assets, not a separate translation-provider component.
