# @adecore/database-win32-x64

The prebuilt native helper of [`@adecore/database`](https://www.npmjs.com/package/@adecore/database) for Windows on x64. It holds one file, `bin/adecore-database.exe`.

Do not install this package yourself. `@adecore/database` lists it as an optional dependency, and the package manager installs the one that matches the machine. `helperPath()` from `@adecore/database/host` returns the path of the binary.
